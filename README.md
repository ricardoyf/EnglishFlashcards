# EnglishFlashcards

Aplicación web para practicar vocabulario inglés-español con tarjetas interactivas.

## Estado

Versión visible: **v1.0**.

## Funciones

- Organiza las tarjetas por categorías.
- Permite practicar desde móvil u ordenador.
- Puede instalarse como aplicación web.
- Funciona sin conexión mediante service worker.
- No necesita servidor ni compilación.

Web: <https://ricardoyf.github.io/EnglishFlashcards/>
